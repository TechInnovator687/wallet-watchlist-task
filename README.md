# Wallet Watchlist

Take-home for a fullstack engineer (JavaScript).

## Start here

You are on **`main`**.

**Check out `assessment` to get the assignment:**

```bash
git checkout assessment
```

Then open **`assessment.md`** and follow it.

## What is in the codebase

- `src/server/ledger.js` - watchlist and treasury balance
- `src/server/request-handlers.js` - HTTP-style request handlers
- `src/client/index.html` - watchlist page
- `src/client/watchlist-app.js` - UI behavior
- `src/client/watchlist-app.css` - page styles
